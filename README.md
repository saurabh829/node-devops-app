# Node.js DevOps Demo Application

This project is a minimal Node.js service designed to demonstrate
**production-grade DevOps practices**.

## Endpoints
- `GET /health` – Health check endpoint
- `GET /api/version` – Build and commit information

## DevOps Focus
- CI/CD with Jenkins & GitHub Actions
- Kubernetes-ready design
- Observability & reliability
- Security and cost-aware architecture

## Usage
```bash
npm install
npm test
npm start
